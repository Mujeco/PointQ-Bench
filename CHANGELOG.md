# Changelog

## Initial staged release

- Author-designated camera-ready paper, citation metadata, and a static project
  page with a procedural point-cloud chicken demo.
- Public Baidu mirror of 3,083 selected point clouds and 18,498 six-view PNGs,
  with four cloud archive parts, SHA-256 checksums, merge instructions, and a
  per-cloud manifest.
- Sanitized evaluation code and portable data validation tooling, documented
  separately from historical, machine-specific experiments.
- Expert annotation and final model-output bundles remain separate pending
  final version pairing. This release does not claim complete offline
  reproduction of every paper table.

No numerical model leaderboard is added until the released outputs are paired
with the exact paper version.
